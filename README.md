# Faizan Norat — Futuristic Portfolio

A responsive portfolio in plain HTML, CSS and JavaScript. No build tools or framework required.

## Preview
Open `index.html` in your browser.

## Publish to GitHub Pages
1. Open your GitHub repository.
2. Upload `index.html` and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/(root)`, then save.
5. Wait for the published URL.

## Before publishing
- Replace `TON.EMAIL@EXEMPLE.COM` in `index.html` with the email address you want to publish.
- Review project descriptions and make sure they accurately reflect your own contribution.
- Replace the CSS-generated mockups with real screenshots when ready.
- Never publish credentials, private data or confidential company/school material.

The site includes a FR/EN toggle, responsive navigation, project filters, project detail modals and CSS-generated visual mockups.
